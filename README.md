# LibriMind

LibriMind is an agentic AI-powered university library assistant
designed to help students access library resources and services.

## Project Overview

LibriMind will provide an interactive platform where students
can search for books, check laptop availability, explore library
spaces, and manage study room bookings.

The system will combine an AI assistant with traditional library management features to create a more accessible and efficient student experience.

## Planned Features

- AI-powered library assistant
- Book search and reservations
- Study room booking and management
- Laptop catalogue and availability
- Interactive library floor plans
- 3D study room previews
- Secure student authentication
- Model Context Protocol (MCP) integration

## Technology Stack

- Frontend: React and TypeScript
- Backend: Python and FastAPI
- Database: SQLite and SQLAlchemy
- AI: Configurable OpenAI integration and mock mode
- 3D Visualisation: Three.js
- Version Control: Git and GitHub
